# CampusSpace Tracker

A cross-platform mobile application for checking classroom availability and managing room booking requests at IIIT Sri City.

## Problem Statement

Classroom bookings are not easily visible to students, clubs, and faculty. This creates scheduling conflicts and requires room reservations to be coordinated manually through the academic office.

## Objectives

- View classroom availability by time.
- Submit room booking requests for club activities and other events.
- Display room details such as number, capacity, and floor.
- Reduce scheduling conflicts and improve room utilization.
- Support administration through booking and permission management.

## Tech Stack

- **Frontend:** React Native
- **Backend:** Java Spring Boot
- **Database:** MySQL / PostgreSQL
- **API:** Spring Boot REST APIs

## Data Requirements

- Classroom details: room numbers, capacities, and floor locations.
- Academic timetables.

## Planned Features

- Check room availability by hour.
- Submit and manage booking requests.
- Provide booking reasons and duration details.
- Support administrative permissions.
